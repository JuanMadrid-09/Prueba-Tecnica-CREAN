# Prueba Técnica CREAN

Bienvenido.

La información de la prueba se encuentra organizada de la siguiente manera:

- **01_Prueba**: descripción del caso y requerimientos.
- **02_Datos**: fuentes de información necesarias para desarrollar la solución.

## Consideraciones sobre los datos

- Cada conjunto de datos se entrega en un archivo **.zip** independiente.
- Dentro de cada archivo comprimido encontrará una base de datos **SQLite (.db)** con la información correspondiente.
- Cada base de datos contiene una única tabla con hasta **1 millón de registros**.
- Puede utilizar cualquier herramienta compatible con SQLite para consultar la información, como **SQLiteStudio**, **DB Browser for SQLite**, **DBeaver**, **VS Code** o librerías de Python.

## Entrega

La solución deberá entregarse a través de un repositorio de GitHub, incluyendo tanto el código desarrollado como las instrucciones necesarias para su ejecución.
